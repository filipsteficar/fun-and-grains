# Fun & Grains

A vegan food blog by Viktorija Jakšić, built with Astro.

## Quick Start

```sh
bun install
bun dev
```

- `bun install` - Install dependencies
- `bun dev` - Start the development server at http://localhost:4321
- `bun build` - Build for production to `./dist/`
